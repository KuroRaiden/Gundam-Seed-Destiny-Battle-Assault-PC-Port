# 0.1.7

- F1 movelist for all 27 JP roster entries, using D-pad and A/B/L/R glyphs.
- Air-only/air-compatible input labels and per-character Berserker types.
- Turbo uses keyboard Tab exclusively; RT/R2 no longer fast-forwards.
- Portable cleanup: config/, resource/, and Logs/, preserving existing settings.

F1 pauses offline play; online matches keep running. The movelist documents
simplified controls. No move descriptions are included.

When upgrading from 0.1.6 or earlier, extract the ZIP over the existing portable
manually. The older updater cannot read the new folder layout. Settings migrate
on the first launcher start. Game files, saves, names, palettes and controls are
preserved. ROMs and BIOS are not included.
